Méthodologie

Source des données

Dataset : IBM Telco Customer Churn
Source : Kaggle
Taille : 7 043 clients

Variable cible : CLV

Le Customer Lifetime Value (CLV) est calculé selon la formule :

CLV = MonthlyCharges × tenure

Note : Il s'agit d'un proxy construit et non d'une variable native du dataset. Cette formule représente la valeur totale historique générée par le client.

Modèle utilisé

Algorithme : CatBoost Regressor
Variables prédictives : 16 features (profil de services uniquement)

Le modèle prédit la valeur potentielle à partir du profil de services du client (16 variables), sans connaître sa durée d'abonnement réelle. Le type de contrat agit comme indicateur indirect de fidélité.
